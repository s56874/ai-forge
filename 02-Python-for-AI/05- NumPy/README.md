# NumPy

## Overview

This folder contains my learning and practice of **NumPy** as part of my journey in **Python for Data Science, Machine Learning, and Artificial Intelligence**.

**NumPy (Numerical Python)** is a powerful Python library used for numerical computing. It provides efficient multi-dimensional arrays and mathematical functions for performing operations on numerical data.

NumPy is widely used in **Data Science, Machine Learning (ML), Artificial Intelligence (AI), Data Analysis, Scientific Computing, and Deep Learning**.
