#  Python Data Structures Assessments

## Overview

This repository contains my **Python Data Structures Assessments** developed after completing Python fundamentals. These assessments focus on applying **Lists, Tuples, Sets, and Dictionaries** to solve real-world problems using menu-driven programs.

The goal of this repository is to strengthen problem-solving skills, understand how different data structures work together, and build a solid foundation before learning Functions, File Handling, Object-Oriented Programming (OOP), and Data Structures & Algorithms (DSA).
