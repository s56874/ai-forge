## Overview

Machine Learning (ML) is a part of Artificial Intelligence (AI) that allows computers to learn patterns from data and make predictions or decisions.

In this section, I learned the fundamentals of Machine Learning, data preprocessing, supervised learning, unsupervised learning, model evaluation, and common ML algorithms.

This folder contains my learning notes, practical coding exercises, and Machine Learning concepts.

## 2. Supervised Learning

Supervised Learning uses labeled data to learn the relationship between input features and the target.

### Regression

Used for predicting continuous numerical values.

Algorithms covered:

* Linear Regression
* Multiple Linear Regression
* Polynomial Regression
* Ridge Regression
* Lasso Regression
* Elastic Net
* Decision Tree Regression
* Random Forest Regression
* SVR
* XGBoost Regression

### Classification

Used for predicting categories or classes.

Algorithms covered:

* Logistic Regression
* K-Nearest Neighbors (KNN)
* Decision Tree
* Random Forest
* Naive Bayes
* Support Vector Machine (SVM)
* XGBoost

---

## 3. Unsupervised Learning

Unsupervised Learning works with data without predefined target labels.

Topics covered:

* Clustering
* K-Means
* Hierarchical Clustering
* DBSCAN
* Gaussian Mixture Models
* Principal Component Analysis (PCA)
