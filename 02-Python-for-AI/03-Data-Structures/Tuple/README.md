#  Python Tuples

##  Overview

This folder contains my learning and practice of **Python Tuples** as part of the **Microsoft AI Nirmaan Program – Python for AI**.

A **Tuple** is one of Python's built-in data structures. It is an **ordered**, **immutable** (cannot be changed after creation) collection that allows multiple values to be stored in a single variable. Tuples can contain different data types and are commonly used to store fixed data, improve performance, and safely organize information in AI, Machine Learning, Data Science, and software development.
