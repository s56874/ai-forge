# Control Flow in Python

##  Overview

Control Flow is the order in which a program executes instructions. It enables Python programs to make decisions, repeat tasks, and control execution based on conditions.

This section covers the fundamental concepts of decision-making and looping, which are essential for solving programming problems and building AI applications.

---

##  Topics Covered

### Decision Making
- if Statement
- if...else Statement
- if...elif...else Statement
- Nested if
- Match Case (Python 3.10+)

### Loops
- for Loop
- while Loop

### Loop Control Statements
- break
- continue
- pass

### Practice
- Pattern Programs
- Decision-Making Problems
- Loop-Based Problems
