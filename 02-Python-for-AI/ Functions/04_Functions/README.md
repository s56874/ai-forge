# Python Functions

## Overview
This folder contains my learning and practice of **Python Functions** as part of the **Microsoft AI Nirmaan Program – Python for AI**.

A **Function** is a reusable block of code that performs a specific task. Functions help organize programs, reduce code duplication, improve readability, and make applications easier to maintain. They are an essential concept in Python programming and are widely used in Artificial Intelligence (AI), Machine Learning (ML), Data Science, Automation, and Software Development.
