#  Python Sets

##  Overview

This folder contains my learning and practice of **Python Sets** as part of the **Microsoft AI Nirmaan Program – Python for AI**.

A **Set** is one of Python's built-in data structures. It is an **unordered**, **mutable**, and **unique** collection that stores only distinct elements. Sets automatically remove duplicate values and are widely used for membership testing, removing duplicates, mathematical set operations, and data processing in Artificial Intelligence (AI), Machine Learning (ML), and Data Science applications.
