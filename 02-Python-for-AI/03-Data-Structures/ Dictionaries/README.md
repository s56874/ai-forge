#  Python Dictionaries

##  Overview

This folder contains my learning and practice of **Python Dictionaries** as part of the **Microsoft AI Nirmaan Program – Python for AI**.

A **Dictionary** is one of Python's most powerful built-in data structures. It is a **mutable**, **ordered** (Python 3.7+), and **key-value pair** collection that stores data in the form of keys and values. Dictionaries provide fast data retrieval and are widely used in Artificial Intelligence (AI), Machine Learning (ML), Data Science, web development, and automation.
