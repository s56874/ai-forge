##  Overview

**Matplotlib** is one of the most widely used Python libraries for data visualization. It allows us to transform raw numerical data into meaningful charts and graphs.

Matplotlib provides high flexibility and customization, making it useful for creating simple as well as advanced visualizations.

It is commonly used in:

- Data Analysis
- Data Science
- Machine Learning
- Artificial Intelligence
- Scientific Computing
- Business Analytics
- Research

# 📚 Topics Covered

## 1. Introduction to Matplotlib

Learned the basics of Matplotlib and how to create visualizations using Python.

### Importing Matplotlib

```python
import matplotlib.pyplot as plt
```

### Basic Functions

```python
plt.show()
plt.figure()
```

---

## 2. Line Plot

A line plot is used to visualize trends and changes over time.

### Real-World Examples

- Monthly sales
- Temperature changes
- Stock prices
- Website traffic
- Student performance

### Function Used

```python
plt.plot()
```

---

## 3. Bar Chart

A bar chart is used to compare values between different categories.

### Real-World Examples

- Product sales
- Student marks
- Department-wise employees
- Monthly revenue

### Functions Used

```python
plt.bar()
plt.barh()
```

---

## 4. Scatter Plot

A scatter plot is used to understand the relationship between two numerical variables.

### Real-World Examples

- Study hours vs marks
- Experience vs salary
- House area vs price
- Advertising cost vs sales

### Function Used

```python
plt.scatter()
```

---

## 5. Histogram

A histogram is used to understand the distribution of numerical data.

### Real-World Examples

- Salary distribution
- Student marks distribution
- Customer age distribution
- Product price distribution

### Function Used

```python
plt.hist()
```

---

## 6. Pie Chart

A pie chart is used to represent proportions and percentages.

### Real-World Examples

- Market share
- Monthly expenses
- Product category sales
- Budget allocation

### Function Used

```python
plt.pie()
```

---

## 7. Chart Customization

Learned how to make charts more informative and readable.

### Functions Used

```python
plt.title()
plt.xlabel()
plt.ylabel()
plt.legend()
plt.grid()
plt.figure(figsize=(10, 5))
```

---

## 8. Multiple Plots

Learned how to display multiple visualizations for better comparison and analysis.

### Functions Used

```python
plt.subplot()
plt.subplots()
```
